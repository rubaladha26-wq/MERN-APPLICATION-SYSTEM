# MERN-APPLICATION-SYSTEM
# Student Management System

A simple Student Management System built using the MERN Stack.

## Technologies Used
- React.js
- Vite
- Node.js
- Express.js
- MongoDB
- Mongoose
- Axios

## Features
- Add students
- View students
- Delete students
- Store student data in MongoDB

## Project Structure
```text
MERN-APPLICATION-SYSTEM/
├── frontend/
└── backend/
```

## Run the Project

### Frontend
```bash
cd frontend
npm install
npm run dev
```

### Backend
```bash
cd backend
npm install
npm run dev
```
