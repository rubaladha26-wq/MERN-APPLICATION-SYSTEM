# MERN-APPLICATION-SYSTEM
# 🎓 Student Management System

A simple full-stack **Student Management System** built using the MERN Stack (MongoDB, Express.js, React.js, Node.js).

## 📌 About the Project

The Student Management System is a web application designed to manage student records easily. It allows users to add, view, and delete student details through a simple and user-friendly interface.

## 🚀 Technologies Used

- **Frontend:** React.js, Vite, CSS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **HTTP Client:** Axios
- **Tools:** VS Code, Git, GitHub

## ✨ Features

- Add new student details
- View all students
- Delete student records
- MongoDB database integration
- Responsive user interface

## ⚙️ Installation and Setup

### 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Setup Backend

```bash
cd backend
npm install
npm run dev
```

### 3. Setup Frontend

Open a separate terminal:

```bash
cd frontend
npm install
npm run dev
```

### 4. Configure MongoDB

Create a `.env` file inside the backend folder:

```env
PORT=5000
MONGO_URI=your_mongodb_connection_string
```

## 🌐 Application URLs

- Frontend: http://localhost:5173
- Backend: http://localhost:5000
